# 카드 체스 추가 완료본

## 적용

- `cardchess-update.zip`: 기존 앱 폴더에 압축을 풀어 index.html, style.css를 교체하고 cardchess.js를 추가하세요. 세 파일 모두 생략 없는 전체 파일입니다.
- `board-games-complete.zip`: 기존 게임 3개와 이미지 assets까지 포함한 전체 실행본입니다. 별도 폴더에 풀어 사용할 수 있습니다.
- 기존 호스팅에 올릴 때 파일 이름과 assets 폴더 위치를 유지하세요. HTTP/HTTPS 실행을 권장합니다. 파일을 직접 열어 Worker가 제한되면 짧은 시간 제한의 메인 화면 AI 계산으로 전환됩니다.

## 기준 프로젝트

직전 ‘3층 오목 이동·표시·터치 개선’ 결과의 index.html, style.css, threelevel.js를 기준으로 적용했습니다. app.js, morris.js, assets는 그 이전 전체 프로젝트에서 가져왔습니다. 기존 세 게임의 JS 파일은 원본과 바이트 단위로 동일합니다.

## 카드 체스

한 세트 AI 대전입니다. 보통/어려움, 진영 색, 선후공을 선택합니다. 후공인 사람은 자기 2장과 AI 2장을 순서대로 선택합니다. 후공 AI는 가능한 전체 배치 30개를 평가하고 보통은 상위 10개, 어려움은 상위 3개에서 가중 랜덤으로 고릅니다.

카드 선택 → 움직일 수 있는 내 말 선택 → 목적지 선택. 같은 카드나 말을 다시 누르면 선택을 취소할 수 있습니다. 사용 카드와 대기 카드가 교환됩니다. 말마다 전진 방향을 보관하며 진행 방향의 끝줄에서 반전합니다. 성 침입은 말의 고유 ID로 추적하고 상대의 다음 턴 종료 후 생존 여부를 판정합니다. 전체 말이 2개가 되면 카드 위치에 관계없이 점퍼가 퀸으로 동작합니다.

어려움 AI는 alpha-beta와 수 정렬을 사용한 반복 심화 탐색으로 최대 5 ply를 목표로 하며, 약 650ms 계산 예산에 따라 완료한 깊이의 결과를 사용합니다. 모바일 성능에 따라 3 ply 미만에서 끝날 수 있습니다. 일반 실행에서는 Web Worker로 화면과 분리합니다.

사용자 제공 카드/5×5 판 레퍼런스의 어두운 판, 파란 이동 패턴과 기존 포메라니안 이미지를 사용했습니다. 새 이미지는 생성하지 않았습니다.

## 미정 규칙 처리

합법수가 전혀 없는 경우의 패스·패배·무승부는 제공 규칙에 없습니다. 임의 결과를 정하지 않고 안내와 다시 하기/설정 이동을 제공합니다. 끝줄 방향 전환은 현재 진행 방향의 끝줄에 도착할 때 적용합니다.

## 검증

- 카드 체스 11개 규칙 테스트 묶음 통과: 이동 패턴, 점프/포획, 카드 순환, 방향 반전, 성 대기/포획 해제, 모든 카드 위치에서 퀸 변환, AI 배치 다양성, 승리/방어, 연속 대국 불변조건.
- 기존 3층 오목 규칙 9개 묶음 및 직접 터치/3층→3층 이동/라운드 UI 테스트 통과.
- 전체 JS 문법, DOM ID 참조 및 중복 여부 검사 통과.
- 앱 내 브라우저에서 카드 이동과 보통 AI 응수, 사람 카드 배치 및 어려움 AI 첫 수 확인.
- 기존 오목/모리스/3층 오목의 화면 진입·시작·착수 확인. 브라우저 오류 로그 없음.
- 320, 375, 390, 430px 화면 너비에서 가로 넘침 없음. 390×844 화면으로 시각 확인.
- 실제 iPhone Safari 기기 검증은 수행하지 않았습니다.

## 로컬 2인 플레이 — 2026-09-15

홈에서 게임을 고른 뒤 **혼자 하기 / 둘이 하기**를 선택합니다. 다섯 게임 모두 지원하며, 둘이 하기에서 BLACK은 PLAYER 1, WHITE는 PLAYER 2입니다. 재대결은 현재 모드를 유지합니다.

- 혼자 하기의 진영 선택, 보통/어려움 AI, 기존 규칙은 유지됩니다.
- 모리스의 mill 제거와 3층 오목의 연속 기본 배치는 해당 플레이어가 끝까지 진행합니다.
- 카드 체스는 후공이 자기 카드 2장, 선공 카드 2장을 고릅니다. 남은 1장은 대기 카드입니다. 시작·배분 완료·턴 전환에는 기기를 넘기고 **준비됐어요**를 누릅니다. 준비 전에는 손패를 표시하지 않으며, 상대 손패도 게임 화면에 노출하지 않습니다.
- 쿼리도는 자기 강아지 선택 → 목적지, 벽 틈 첫 터치 → 고정 미리보기 → 같은 위치 재터치로 설치하는 기존 방식을 유지합니다.
- 공통 `play-mode.js`가 모드·입력 권한·화면 전환 정리를 담당합니다. AI 진입점과 비동기 응답에는 모드 및 세션 검증이 적용됩니다.
- 전적의 기존 BLACK/WHITE 전체·오늘 점수를 유지합니다. 새 결과는 `modes.solo` 또는 `modes.local2p`에도 기록되며, 기존 기록의 모드는 추정하지 않습니다.
- 서비스 워커 캐시: `pompom-board-club-v2-local2p`. 새 파일과 강아지 이미지를 사전 캐시하며, 상대 경로를 유지합니다.

브라우저 검증: 42개 플레이·회귀 항목, PWA v1→v2 전환 14개 항목, 기존/빈/손상된 전적 데이터 검증 통과. 320px·390px 레이아웃 및 쿼리도 실제 포인터 입력 확인. 규칙·AI 계산 함수는 기존 소스와 동일함을 비교했습니다. 실제 iPhone의 Safari/홈 화면 실행 및 햅틱은 기기에서 최종 확인해야 합니다.
